# TaskTracker

## Descrição
Aplicação de linha de comando para cadastrar e visualizar tarefas.

## Tecnologias
- Python 3
- Git
- GitHub

## Estrutura
- `src/main.py`: código principal.
- `docs/planejamento_logico.pdf`: planejamento da Fase 1.

## Como executar
No terminal, a partir da raiz do projeto:

```bash
python src/main.py
```
